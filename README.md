# Harness

Harness is a collection of small Pi packages.

## AWF tracker storage

The `@albizures/awf` CLI uses a filesystem tracker directory by default (`.awf/tracker`), where each Workflow issue is stored as an inspectable Markdown issue file such as `1.md`. See `packages/awf/README.md` for the tracker directory layout and issue file format.

## Developing Pi extensions

See `.pi/README.md` for the local Pi smoke-testing setup.
